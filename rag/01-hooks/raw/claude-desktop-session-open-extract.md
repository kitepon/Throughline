# Claude Code: 既存の会話をDesktopで開く

- 出典: [Desktop application — Coming from the CLI?](https://code.claude.com/docs/en/desktop#coming-from-the-cli)
- 取得日: 2026-10-06
- 確度: 公式仕様

既存のCLI会話を開く公開コマンド:

```sh
claude --desktop --resume <session-id>
```

> Claude Code doesn’t move a session that is open in another terminal or still running in the background.

画面での確認結果は[Desktop受入記録](https://github.com/kitepon/Throughline/blob/main/evidence/2026-10-05-claude-auto-handoff.md#完了した後継をdesktopで開く)に置く。
